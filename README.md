# Multimodal-Foamy-Slag-Detection-in-an-Electric-Arc-Furnace

This project demonstrates a proof-of-concept multimodal deep-learning system for classifying foamy and non-foamy slag using EAF images and synthetic process data. 

The dataset contains 18 related frames extracted from a YouTube video published by the **Alec Steele** channel. Both the image-only and multimodal models achieved perfect validation metrics, so loss values were used for additional comparison. Due to the small dataset, synthetic process data, temporal similarity, and scene bias, the results demonstrate only the feasibility of the workflow, not validated industrial performance. 

Future development requires real images and synchronized process measurements from multiple EAF heats.
